# 2026-09-22 右折した前車に追突する（past_laneの導入）

前車が右折コネクタに入った瞬間にブレーキが切れて、後続車がそのまま突っ込む。

## 原因：lane_nameが変わって同レーン判定から外れる

`11_CONNECT_LANE.vfl`はコネクタに**行き先レーンの`lane_name`を継承**させている。つまり前車が右折コネクタへ乗った瞬間、その`lane_name`は右折先のレーン名に変わる。

`06_CAR DETECT.vfl`の同レーン判定は2本しか見ていなかった。

```c
int same_lane = (other_lane_name == s@lane_name)      // まだ自分と同じレーン
             || (other_lane_name == s@next_lane_name); // 自分が次に行くレーン
```

自分が直進、前車が右折だと**どちらにも一致しない**。落ちた先は交差車の分岐で、

- `cross_curves`は自分の直進レーンと交錯する右折カーブの一覧。**自分のレーンから出ていった前車は交錯していない**ので一致しない
- レーン非依存のフォールバックは`vel < 0.5`が条件。曲がりながら走っている前車は拾えない

結果、前車が検知対象から完全に消えて`f@dist_to_car`が9999のまま＝IDMが働かない。

## 変更内容：`s@past_lane`

直前まで走っていた`lane_name`を車に持たせ、「自分のレーンから出ていった車」を同レーン扱いにする。

| ノード | 変更 |
|---|---|
| `01_INIT` | `s@past_lane = ""` の初期値 |
| `02_CHANGE ROAD` | `s@lane_name`を上書きする前に退避 |
| `06_CAR DETECT` | 同レーン判定に1本追加 |

```c
string other_past = point(0, "past_lane", pt);   // 空同士で一致させない
int same_lane = (other_lane_name == s@lane_name)
             || (other_lane_name == s@next_lane_name)
             || (other_past != "" && other_past == s@lane_name);
```

`other_past != ""` のガードは必須。`s@lane_name`が空の車がいると、`"" == ""`で無関係な車まで全部同レーンになる（`next_turn`の`""`を直進扱いにしたときと同じ罠）。

### 名前について

Road Line側にも`prev_lane`があるが、こちらは**コネクタprimのint（入口の`lane_id`）**で意味も型も違う。同名にするとスプレッドシートで並んだときに区別できないので、車側は`past_lane`（string、`lane_name`）にした。

### 副作用

- 前車が右折を終えて別方向へ離れていっても、次に乗り換えるまで`past_lane`は自分のレーン名のまま残る。ただし同レーン分岐は`fwd_dot >= 0.6`のコーンを要求するので、90度曲がって離れた車はすぐコーンから外れる
- 右折待ちで止まっている前車は、これまで`yield_conflict == 1`の除外（譲っている車を障害物扱いしない）で捨てられていた。同レーン判定はその除外より手前にあるので、**自分のレーンから出ていった車には効かなくなる**。自分の前で止まっている車なら止まるのが正しいので、これは意図どおり
- `07_RESOLVE_CONFLICT.vfl`の`lead_headway`は`i@car_is_cross == 0`のときだけ効く。右折した前車が同レーン扱い（`is_cross = 0`）になったので、右折車のt_ego見積もりにも前車の分が入るようになる

## 確認すること

- 前車が右折を始めた瞬間に`i@car_ptnum`が-1へ飛ばないか（飛ぶなら`past_lane`が伝わっていない）
- 後続車が交差点手前で減速するか。`i@car_is_cross`が0、`i@car_stalled`が0で拾えているか
- 右折車の後ろに続く車が、前車の右折完了後も不要に追従し続けていないか
