# 2026-09-21 交差点内に取り残された車をレーン非依存で検知する

右折車は直進車を待つぶん交差点内に最も長く留まる。自分のフェーズが終わって交差道路が青になったとき、そこに残っていると交差道路の車に突っ込まれる。

## 原因：交差道路の車には、残っている右折車が「見えていない」

`06_CAR DETECT.vfl` の検知経路は2つしかない。

- `lane_name` / `next_lane_name` 一致 → 同レーンの前車
- 自分の `cross_curves` に載っているレーン → 交差車（**`cross_curves` は右折車しか持たない**）

交差道路から青で入ってくる直進車にとって、交差点内に残った右折車は**どちらにも当てはまらない**。存在しない点として扱われ、そのまま通り抜ける。右折車側の検知範囲をどう広げても直らない。取り残された車は既に停止していて、検知しても打てる手がないため。

## 変更内容：速度・距離・横ズレだけで見る第3の経路

`cross_curves` に無いレーンの相手を `continue` で捨てず、物理的な位置関係だけで判定するフォールバックへ流す。

```c
float stalled_vel      = 0.5;    // m/s（これ未満を取り残されているとみなす）
float stalled_range    = 15.0;   // m
float stalled_dot      = 0.9;    // 正面に近いものだけ
float stalled_corridor = 1.5;    // m（横方向の許容＝半車線）
...
} else {
    if (point(0, "vel", pt) >= stalled_vel) continue;
    if (d > stalled_range)                  continue;
    if (fwd_dot < stalled_dot)              continue;
    float lat = length(to_other - (fwd_dot * d) * normalize(v@dir));
    if (lat > stalled_corridor)             continue;
    is_cross   = 1;
    is_stalled = 1;
}
```

**止まっていることを必須条件にしている**のが要点。走行中の他レーンの車（対向直進、隣車線）は速度で落ちるので、通常の交通流には一切触れない。効くのは「止まっている」「15m以内」「ほぼ正面」「横ズレ半車線以内」を同時に満たす相手だけで、それは事実上「自分の進路を塞いでいる車」しかない。

## 他の処理への影響と、その潰し方

### 1. `07` の `lead_headway` が壊れないようにする

```c
if (i@car_ptnum >= 0 && i@car_is_cross == 0 && f@dist_to_car < e_dist) {
    float t_lead = (e_dist - f@dist_to_car) / max(f@car_vel, v_floor);
```

07はこれを「同レーンの前車」として使い、自分が交錯点に着く時間の下限にしている。フォールバックで拾った相手を `car_is_cross = 0` のまま渡すと、別の道路で止まっている車を前車とみなして `t_ego` を計算してしまう。

**`is_cross = 1` を立てることで回避。** 07はこの条件で除外し、09は静止障害物向けの `s0 = 5.0` / `T = 1.0`（[09_ACCEL.vfl:11-14](09_ACCEL.vfl#L11-L14)）を使う。止まっている車が相手なので、どちらも意味的に正しい。

### 2. 譲り合いのデッドロックを作らない

`yield_conflict == 1` の相手を除外する既存ルール（譲っている車は待たせる側）を、**フォールバックも通るように `cross_idx` の判定より前へ移した**。これが無いと、譲って停止している右折車を直進車が障害物として検知して止まり、互いに待ち合う。

副作用として、**譲っている間の右折車は交差道路からも見えない**。見えるようになるのは `yield_conflict` が 0 に落ちた後、つまり「抜けると決めたのに抜けきれていない」状態のときだけで、守りたいのはまさにその区間。

### 3. 遠距離での誤検知を切る

コーンだけで絞ると、カーブ上では遠方の隣車線が正面に入る（30m先なら進行方向が3度ずれるだけで横1.5m）。`stalled_range = 15.0` で近距離に限定して塞いだ。障害物は近いときにしか問題にならないので、範囲を切っても目的を損なわない。

### 4. 最近傍1台しか採らない仕組みとの関係

06は `d < f@dist_to_car` で最も近い1台だけを残す。フォールバックが増やせるのは候補だけなので、`dist_to_car` は短くなる方向にしか動かない。かつ `stalled_dot = 0.9` は同レーン判定の `same_dot = 0.6` より狭いので、正当な同レーン前車を横取りするのは「より近く、より正面にいる停止車」がいる場合だけ。それは本当に止まるべき相手。

### 5. 残る挙動の変化

**これまで通り抜けていた場所で止まるようになる。** 衝突がグリッドロックに変わるケースはあり得る（互いの進路上で止まった2台が、互いを障害物として見続ける）。増えるのは停止理由だけなので衝突を生むことはないが、詰まるようなら `stalled_range` を縮める。

## 本命は信号側の全赤

これはシミュレーション側の保険であって、根本対策ではない。実際の交差点は**全赤（clearance interval）**で残留車が抜ける時間を確保している。`signal_state` はTraffic Signal側のジオメトリが持っていて[04_SIGNAL DETECT.vfl:29](04_SIGNAL%20DETECT.vfl#L29)はそれを読むだけなので、これらVFLの外側で数秒の全赤を入れるのが一番効く。

## 確認すべきこと

- `i@car_stalled == 1` が立つのは、交差点内に停止車が残っている瞬間だけであること。通常の直進流で立つなら `stalled_corridor` か `stalled_range` が広すぎる
- 立ったときの `i@car_ptnum` が本当に交差点内の車を指しているか（別の道路の停止車を拾っていないか）
- 右折車が譲っている間は立たないこと（立つなら 2 の除外が効いていない）
