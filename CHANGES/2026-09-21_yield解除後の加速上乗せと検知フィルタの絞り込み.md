# 2026-09-21 yield解除後の加速上乗せと、検知フィルタの絞り込み

## 1. 譲り終えた直後だけ加速を上乗せする

右折車はyieldが解けた時点で交錯点の1m手前に停止している。そこからIDMの通常加速で発進すると、交錯点（＝対向レーンの真上）を抜けるまでに時間がかかり、次の対向車が来る余地を残す。

### `07_RESOLVE_CONFLICT.vfl`：解除の瞬間にカウンタを立てる

```c
int boost_frames = 48;
...
// 代入前の @yield_conflict は前フレームの値なので、1→0 の立ち下がりが取れる
if (i@yield_conflict == 1 && any_yield == 0) i@rt_boost = boost_frames;
else if (i@rt_boost > 0)                     i@rt_boost -= 1;

i@yield_conflict = any_yield;
```

解除理由（`go_reason` 1〜3 / 候補消滅）は区別しない。どれも「もう進んでよい」なので扱いは同じ。右折区間を抜けた後（`s@turn != "right"` 側の分岐）でもカウンタは減らし続けるので、コネクタを出てからも残りぶんは効く。

### `09_ACCEL.vfl`：正の加速にだけ掛ける

```c
float rt_boost_gain = 1.5;
if (i@rt_boost > 0 && f@accel > 0) f@accel *= rt_boost_gain;
```

**`a = f@max_accel` 自体を上げない。** IDMの `s_star` は `(vel * delta_v) / (2*sqrt(a*b))` を含むので、`a` を上げると希望車間距離が縮んで前車に詰めすぎる。上乗せしたいのは加速だけなので、出来上がった `f@accel` の正の側にだけ掛ける。`car_state == 1`（減速中）のブランチには入らないので、ブレーキが弱まることもない。

チューニング: `rt_boost_gain`（09）と `boost_frames`（07）。48フレームは長すぎれば短くしてよい。交錯点を抜けた後も速度が乗り続けるようなら `boost_frames` を先に削る。

## 2. 交差車の検知に方向コーンを入れた

`06_CAR DETECT.vfl` の交差車（`car_is_cross = 1`）判定は、相手が自分より後方でないことしか見ていなかった。

```c
// 変更前
if (fwd_dot < 0.0) continue;
// 変更後
float cross_dot = 0.1;   // 宣言は same_dot の隣
if (fwd_dot < cross_dot) continue;
```

`fwd_dot >= 0` は180度の半空間なので、**真横に並んだ車まで前車として掴む**。掴むと `f@dist_to_car` / `f@car_vel` がその車の値になり、IDMが真横の車に対して車間を取ろうとする。0.1（約84度）で真横だけを落とす。

### `07_RESOLVE_CONFLICT.vfl` には同じコーンを入れていない

07の候補は「自分の前方にいるか」ではなく「**交錯点にどちらが先に着くか**」で判断している。右折中は自車の `dir` が最大90度回るので、正当な脅威である対向車が自車から見て真横〜後方に来る。ここに方向コーンを入れると、曲がり始めた瞬間に相手を見失う。07で位置関係を見ているのは `opp_clear`（相手が交錯点を抜けたか）だけで十分。

## 3. 対向の右折車を候補から外す（`07_RESOLVE_CONFLICT.vfl`）

候補フィルタは相手レーンの一致しか見ていないので、**対向車線から右折しようとしている車**も交錯の相手として拾っていた。相手が右折コネクタに乗っていれば、そのまま曲がって自分のレーンへ抜けていくので、こちらの交錯点（対向の直進レーンとの交点）は渡らない。むしろ相手も同じ「譲る側」なので、互いに待ち合う。

```c
// ★ s@turnは03が毎フレーム現在のレーンから読み直すので、コネクタ上でだけ "right"
if (point(0, "turn", pt) == "right") continue;
```

`s@turn` はレーン由来なので、**まだ直進の進入レーンにいる段階では "right" にならない**（右折するつもりでも、コネクタに乗るまでは `"straight"`）。つまりこの条件で落ちるのは「既に曲がり始めている車」だけで、これから交錯点を横切る可能性のある車は残る。

`i@dbg_n_lane` はこの条件を通過した数に変わった（レーン一致かつ右折中でない）。
