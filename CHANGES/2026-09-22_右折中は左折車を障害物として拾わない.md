# 2026-09-22 右折中は左折車を障害物として拾わない

右折車が、進路の交わらない左折車に反応して交差点内で止まる／遅れる。

## 変更内容

`06_CAR DETECT.vfl`で、自分が右折中のときは次の2つを候補から外す。

- `turn == "left"` — 既に左折コネクタに乗っている車
- 直進中（`turn`が`"straight"`または既定の`""`）で`next_turn == "left"` — 手前のレーンで左折待ちの車

`next_turn`単独で外さないのは、コネクタに乗った車の`next_turn`が自分自身のturnになりがちで（`03`が`next_lane_name`で引く最寄り点がコネクタ自身の点になる）、意味が二重になっているため。

```c
int turning_right = (s@turn == "right" || i@rt_lookahead == 1);
```

`rt_lookahead`を含めるのは、右折の判断が1つ手前のレーンから始まるため（`03_UPDATE_LANE_ATTRIB.vfl`の先読み）。コネクタに乗ってからでは遅い。

除外を置いたのは**same_laneでない側の分岐だけ**。左折車と右折車は同じ出口レーンへ合流するので、先に入った左折車は`other_lane_name == s@next_lane_name`でsame_lane側＝通常の前車として拾われる。ここまで外すと合流相手を無視して突っ込む。

`07_RESOLVE_CONFLICT.vfl`は既に同じ除外を持っている（2026-09-21「右折の候補から対向の左折車を外す」）。今回はそれを検知側にも揃えた形。

## 副作用として弱くなるもの

`06`のレーン非依存フォールバック（`CHANGES/2026-09-21_交差点内に取り残された車をレーン非依存で検知する.md`）は、右折中に限り左折車を拾わなくなる。交差点内で止まっている左折車が右折車の正面に居座るケースでは、保険が1枚減る。

右折車から見て左折車が実際に正面（`stalled_dot = 0.9`・横1.5m以内）に来る配置があるなら、除外を`is_cross`側だけに限る（フォールバックには効かせない）方へ戻すこと。

## 確認すること

- 右折車が対向左折車で止まらなくなったか
- 同じ出口レーンへ左折車が先に入ったとき、右折車が前車として追従するか（`i@dbg_follow`と`i@car_ptnum`で確認）
