# 2026-09-21 黄色で減速中の直進車を右折車が脅威として拾う問題

右折車が、**信号が黄色（赤）で停止線に向けて減速している対向直進車**まで交錯の相手として検知し、譲り続けてしまう。相手は交差点に入らず停止線で止まるので、本来は右折車が抜けてよい場面。

## 原因：候補を1つ前のレーンまで広げたぶん、停止線の手前の車まで入ってきた

`07_RESOLVE_CONFLICT.vfl` の候補フィルタは、`lane_name` だけでなく `next_lane_name` も対向レーンとして認める。

```c
if (point(0, "lane_name",      pt) != opp_lane
 && point(0, "next_lane_name", pt) != opp_lane) continue;
```

これは「対向の後続車を見落としてgoに倒れる」問題の対策で、検知範囲が1レーンぶん上流に伸びている（2026-09-20 の変更の 4〜6）。**その上流のレーンには停止線が含まれる。** 停止線に向けて減速中の車は、

- まだ速度を持っている（`t_other` が小さく出る）
- `t_other` は減速を真に受けない式（等速と比べて早い方を採る）で評価される

ため、`blocked = min_t_other < t_ego + safety_margin` が成立し続ける。相手は物理的に交錯点まで来ないのに、TTCの式からはそれが分からない。

## 変更内容：「止まる先が交錯点より手前か」で候補から外す

`07_RESOLVE_CONFLICT.vfl` の候補ループに1条件追加。

```c
float o_dist = distance(t_cp, opp_p);
if (point(0, "car_state", pt) != 0
 && point(0, "ctrl_src",  pt) == 0
 && point(0, "dist_to_signal", pt) < o_dist) { dbg_n_sigstop += 1; continue; }
```

- `car_state != 0` … 減速中(1)か停止中(2)
- `ctrl_src == 0` … その停止目標が**信号**（08_STATEが毎フレーム決める。歩行者は2、コンフリクトは3）
- `dist_to_signal < o_dist` … その停止線が交錯点より手前

3つ揃って初めて「この車は交錯点まで来ない」と言える。

### 「減速している」だけで外してはいけない

`accel < 0` を条件にすると、IDMで前車に合わせて1フレーム緩んだだけの車まで脅威から外れる。**07はむしろ逆に、相手の減速を真に受けないよう明示的に設計してある**（`t_other = min(減速考慮, 等速)`）。ここで外してよいのは「減速している車」ではなく「**停止する位置が交錯点の手前だと分かっている車**」であって、両者は別物。前者は瞬間値、後者は停止目標という状態。

### 黄色の通過コミット中は外れない

`08_STATE.vfl` は黄色を抜けると判断した車に `yellow_commit = 1` / `car_state = 0` を立てる。`car_state != 0` が条件なので、**突っ込んでくる車は候補に残る**。判定に使うのは信号の色ではなく「その車が止まると決めたかどうか」。

### 1フレーム古い値である点

07は08より先に走るので、読んでいる `car_state` / `ctrl_src` は前フレームの値。信号が変わった直後の1フレームだけ判断が古くなるが、候補が消える向きに外れても `clear_frames = 24` のデバウンスがあるので `rt_decided` は動かない。

## `06_CAR DETECT.vfl` にも同じ条件を入れた

右折車が対向直進車を**交差車(`car_is_cross = 1`)として追従対象にする**側にも同じ穴がある。`06` は `cross_curves`（`lane_name` のみ、上流レーンは見ない）で引くので07ほど広くは拾わないが、停止線が交錯点より手前にある構成なら、赤で止まっている対向車をIDMの前車として掴んで右折車が減速する。

```c
if (point(0, "car_state", pt) != 0 && point(0, "ctrl_src", pt) == 0
 && point(0, "dist_to_signal", pt) < distance(cp, point(0, "P", pt))) continue;
```

相手が信号を通過済みなら `04_SIGNAL DETECT` が `dist_to_signal = 9999` を返すので、条件は成立せず候補に残る。**交差点内に居座っている車を見落とす方向には倒れない。**

## 確認すべきこと

- 対向が黄色で減速し始めたフレームから `i@dbg_n_sigstop` が増え、`i@dbg_n_alive` が減ること。`dbg_n_sigstop` が0のままなら、相手の `i@ctrl_src` が0になっていない（前車追従で早期returnしていると -1 のまま）
- 黄色を通過してくる対向車では `dbg_n_sigstop` が増えないこと。増えるなら `yellow_commit` の判定が効いていない
- 停止線と交錯点の位置関係。`dist_to_signal < o_dist` が成立しない配置（信号点が交差点の奥にある等）だと、この条件は一切効かない

## 追加したデバッグ属性

| 属性 | 意味 |
|---|---|
| `i@dbg_n_sigstop` | `dbg_n_lane` のうち、信号で止まるので候補から外した相手の数（全indexの合計） |

段階別カウンタの並びは `dbg_n_cands` → `dbg_n_car` → `dbg_n_lane` → `dbg_n_sigstop`（脱落） → `dbg_n_alive`。
