右折と左折、両方の可能性を定義する必要があるのは、1車線の時のみ
2車線以上なら、どちらか

事前に曲がるattr付与
// --- 車の生成時（一度だけ）---
// 0 = 直進寄り, 1 = 曲がる寄り
@turn_pref = (rand(@id * 7.21) < 0.3) ? 1 : 0;  // 30%の車が曲がる


**左折右折の定義**
// --- 本来は道路定義側で付与すべきattr（暫定でここで定義）---
// 自分が今走っている道路の車線数
// 1 = 単車線（右折・左折を自分で選べる）
// 2以上 = 多車線（レーンで方向が決まっている）
i@lane_count = 1;   // ← 後で road 側から取得する想定


// --- 車の希望方向を決める ---
float r = rand(@id * 7.21);

if (i@lane_count == 1) {
    // 単車線：直進・左折・右折を自由に選べる
    if      (r < 0.6) i@turn_want = 0;   // 60% 直進
    else if (r < 0.8) i@turn_want = 1;   // 20% 左折
    else              i@turn_want = 2;   // 20% 右折
}
else {
    // 多車線：自分のレーンで行ける方向が決まっている
    // → ここでは「直進 or どちらか一方」しか発生しない
    //   片方向の判断は交差点の dirs 側に任せる
    if (r < 0.7) i@turn_want = 0;        // 70% 直進
    else         i@turn_want = 3;        // 30% 「レーンなりに曲がる」
}

**交差点通過後**
// --- 交差点を通過した瞬間 ---
int dirs = i@dirs;
int want = i@turn_want;
int next_lane = -1;

if (i@lane_count == 1) {
    // 単車線：車の希望をそのまま尊重
    if      (want == 0 && (dirs & 1)) next_lane = i@lane_straight;
    else if (want == 1 && (dirs & 2)) next_lane = i@lane_left;
    else if (want == 2 && (dirs & 4)) next_lane = i@lane_right;
}
else {
    // 多車線：交差点が持つ「その方向」に従う
    if (want == 0 && (dirs & 1)) {
        next_lane = i@lane_straight;
    } else {
        // レーンなりに曲がる：dirs にある曲がり方向を採用
        // （多車線交差点は left か right の片方しか持たない前提）
        if      (dirs & 2) next_lane = i@lane_left;
        else if (dirs & 4) next_lane = i@lane_right;
    }
}

// フォールバック（希望が叶わなかった場合）
if (next_lane < 0) {
    if      (dirs & 1) next_lane = i@lane_straight;
    else if (dirs & 2) next_lane = i@lane_left;
    else if (dirs & 4) next_lane = i@lane_right;
}

@road_lane = next_lane;
