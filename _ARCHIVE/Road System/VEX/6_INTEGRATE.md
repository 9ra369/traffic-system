**実装内容：車の位置を計算**
・停止中 → 速度 0
・進行中、ブレーキ中 → 加速度から速度、位置を計算　
　前の段階でブレーキの場合は、減速度になっているから進行中と同じ計算方法

// ════════════════════════════════════════════════════
// INTEGRATE: accel → vel → @P を更新
// POPソルバーの積分を完全に置き換える
// ════════════════════════════════════════════════════
float dt  = @TimeInc;

if (i@car_state == 2) {
    // ── STOPPED: 完全固定 ────────────────────────────
    f@vel = 0.0;
    @v    = {0, 0, 0};

} else {
    // 速度を更新 
    f@vel += f@accel * dt;
    f@vel  = clamp(f@vel, 0.0, f@max_speed);

    //ベクトル速度と位置を更新
    @v  = v@dir * f@vel;
    @P += @v * dt;
}

// ── POPソルバーへの干渉を防ぐ ─────────────────────────
@force = {0, 0, 0};
