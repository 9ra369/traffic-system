## 考え方：位相を「決める層」と「使う層」に分ける

信号のサイクル計算の中で位相を決めるのではなく、**事前に `@phase` を付与しておき、アニメーション側はそれを読むだけ**にする。

|層|役割|ノード|
|---|---|---|
|決める層|位相 `@phase` をどう決めるか|手前の Wrangle|
|使う層|サイクルをどう動かすか|信号アニメの Wrangle|

### この分け方の利点

- **責務が分かれる** — 位相ロジックを差し替えてもアニメ側を触らずに済む
- **設計方針と揃う** — 「attributeは先に定義、シミュレーションはそれを読む」という全体方針と一致
- **再現性** — `@phase` をジオメトリに焼き込むので挙動が安定し、デバッグしやすい

---

## 1. 位相を決める層

`@phase` は 0〜1 で指定する（1周期分に対する割合）。

```vex
// --- lane で決める（交差点で直交する信号を逆にする）---
f@phase = (i@lane == 0) ? 0.0 : 0.5;   // 0.5 = 半周期ずらす

// --- 完全ランダム（動作確認用）---
// f@phase = rand(@ptnum * 3.7);

// --- 等間隔でずらす（リレー状）---
// f@phase = float(@ptnum) / float(npoints(0));

// --- 位置ベース（グリーンウェーブ）---
// f@phase = frac(@P.x / 20.0);   // 20.0 = 波の間隔
```

---

## 2. 位相を使う層（信号アニメ本体）

```vex
// --- パラメータ（秒単位）---
float dur_green  = 5.0;   // 青
float dur_yellow = 2.0;   // 黄
float dur_red    = 5.0;   // 赤
float cycle = dur_green + dur_yellow + dur_red;  // 1周期

// --- 付与済みの phase を使うだけ ---
float t = @Time + f@phase * cycle;
float local = t % cycle;

// --- 状態判定（0=青, 1=黄, 2=赤）---
int state;
if      (local < dur_green)              state = 0;
else if (local < dur_green + dur_yellow) state = 1;
else                                     state = 2;
i@signal_state = state;

// --- 色付け（ビューポート確認用）---
if      (state == 0) @Cd = {0, 1, 0};   // 青
else if (state == 1) @Cd = {1, 1, 0};   // 黄
else                 @Cd = {1, 0, 0};   // 赤
```

---

## インスタンス／モデルアニメの場合

VEXで色・状態を計算するのではなく、**アニメ付きモデルを配置**する場合は、Copy/Instance系が自動解釈する予約アトリビュートを使う。

|アトリビュート|型|効果|
|---|---|---|
|`timeoffset`|float|アニメ開始を秒単位でずらす|
|`timescale`|float|再生速度の倍率|

```vex
f@timeoffset = rand(@ptnum * 1.23) * 5.0;          // 0〜5秒ずらす
f@timescale  = fit01(rand(@ptnum * 9.9), 0.8, 1.2); // 速度に個体差
```

### 使い分け

|信号アニメの作り方|ずらすのに使うもの|
|---|---|
|VEXで色・状態を計算|`@phase`（自分で計算に組み込む）|
|モデルにキーフレームアニメ|`@timeoffset`（Copy/Instanceが自動解釈）|

---

## 注意：全赤（all-red）時間

半周期（0.5）ずらしただけだと、片方が赤になった瞬間にもう片方が青になり、**全赤の余裕がない**（＝実際なら危険なタイミング）。

安全にするには「赤の長さ > 青＋黄」にして全赤時間を作るのが定石。まずは位相が切り替わることを確認してから調整する。
