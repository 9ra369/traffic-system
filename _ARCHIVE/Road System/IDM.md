IDMは物理法則から演繹したものではなく、**「満たすべき性質のリスト」を先に立てて、それを全部満たす最小限の式を構成的に設計した**ものです(現象論的モデル)。Treiber らの論文でもそういう設計思想として書かれています。

### 1. 自由走行項:a

要件は「v=0 で最大加速度 a、v=v₀ で加速度ゼロ、その間を滑らかに接続」。これを満たす最も単純な族が a[1 − (v/v₀)^δ] です。δ は補間の形を決める自由パラメータで、δ→∞ にすると「v₀ までベタ踏み、到達したら即ゼロ」という機械的な挙動に、δ=1 だと指数的に緩やかな接近になります。δ=4 は実測の運転挙動に合う中間値として選ばれただけで、導出根拠はありません。

### 2. 相互作用項が −a(s*/s)² である理由

「車間 s が希望車間 s* に一致するとき、追従平衡が成り立つ」ように設計されています。2乗なのは滑らかさと、後述のブレーキ戦略が綺麗に出るための選択で、これも一意な導出があるわけではなく「うまく機能する最小形」です。

### 3. s* の導出 — ここが一番面白い部分

s∗=s0+vT+v Δv2abs^* = s_0 + vT + \frac{v\,\Delta v}{2\sqrt{ab}}s∗=s0​+vT+2ab​vΔv​

**(a) s₀ + vT:平衡状態の要請から**

定常追従(Δv = 0、加速度 0)を式に代入すると、平衡車間は s = s* = s₀ + vT に収束します。つまりこの部分は「停止時に s₀ 空け、走行中は時間ギャップ T を保つ」という、教習所で習う「○秒ルール」をそのまま平衡条件として埋め込んだものです。導出というより**仕様**です。

**(b) vΔv / 2√(ab):運動学からの導出**

ここだけは本物の導出があります。「知的ブレーキ戦略」と呼ばれる部分です。

前方の停止車両(あるいは遅い車)に速度差 Δv で接近しているとき、距離 s で衝突せずに止まるために運動学的に必要な減速度は、等加速度運動の式 v² = 2bs から:

bkin=(Δv)22sb_{\text{kin}} = \frac{(\Delta v)^2}{2s}bkin​=2s(Δv)2​

ここで、危機的状況(動的項が支配的)での IDM の減速度を計算してみると:

a(s∗s)2≈a⋅(vΔv)24ab s2=(Δv)2⋅v2/(Δv)2⋯a\left(\frac{s^*}{s}\right)^2 \approx a \cdot \frac{(v\Delta v)^2}{4ab\,s^2} = \frac{(\Delta v)^2 \cdot v^2 / (\Delta v)^2 \cdots}{}a(ss∗​)2≈a⋅4abs2(vΔv)2​=(Δv)2⋅v2/(Δv)2⋯​

停止障害物への接近(v = Δv)で整理すると:

減速度=(v2/2s)2b=bkin2b\text{減速度} = \frac{(v^2/2s)^2}{b} = \frac{b_{\text{kin}}^2}{b}減速度=b(v2/2s)2​=bbkin2​​

つまり **「実際の減速度 = 運動学的必要減速度の2乗 ÷ 快適減速度 b」** になるよう、係数 2√(ab) が逆算されているんです。√(ab) という一見不自然な形は、外側の a(…)² と打ち消し合ってこの関係を出すための辻褄合わせです。

### 4. なぜ b_kin²/b が「知的」なのか

この形は自己安定なフィードバックになっています:

- b_kin < b(まだ余裕がある)→ 実減速度は b_kin より**小さい** → 慌てて踏まず、状況が b に近づくのを許す
- b_kin = b → ちょうど b で減速(理想状態)
- b_kin > b(危ない)→ 実減速度は b_kin より**大きい** → 必要以上に強く踏んで早めに安全側へ戻す

どんな初期状況から始めても「快適減速度 b ちょうどで止まる軌道」に吸い込まれていく、という設計です。無事故性が保証されるのはこの機構のおかげです。
