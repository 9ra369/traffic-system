# カーブでの減速と、レーンへの追従

note記事用の本文。速度と位置を更新している[[010_INTEGRATE]]の話。実装に合わせて2026-09-22に更新。

## 本文

**カーブで落とす速度は、曲率から決める**

道路網の各点には、そこがどれだけ曲がっているかを`curv`として0〜1に正規化して焼いてあります。車はこれを毎フレーム読み、`curv=0`なら自分の最高速度、`curv=1`なら徐行速度、という対応で速度の上限を作ります。急なカーブほど上限が下がるので、コーナーに入る前から自然に減速が始まります。

このとき徐行速度を「時速15km」のような絶対値では持たせていません。最高速度は車ごとにランダムに振ってあるので、固定値を書くと、もともと遅い車だけがカーブで不自然に粘ったり、速い車が落とし切れなかったりします。そこで**街全体の平均速度からの比率**として持ち、平均速度を変えればカーブの速度もまとめて追従するようにしています。調整する場所が増えないことのほうが、細かく指定できることより価値があります。

（図：curvの値とコーナーでの速度上限）

**右折で徐行させるのは、実際に譲っているときだけ**

右折は、曲率が緩くても対向車の確認のために徐行してほしい動作です。そこでカーブとは別に、右折専用の速度上限を重ねています。

ただしこれを「右折なら常に」で掛けると、対向車が1台もいない右折までのろのろ進むことになり、交差点の流れが目に見えて悪くなりました。今は**実際に対向車へ譲ると判断している間だけ**上限を掛けています。判断そのものは別のノードが持っていて、ここはその結果を受け取るだけです。

**上限の当て方：一番小さいものを採り、落とし方は加速度で決める**

最高速度・カーブ上限・右折上限の3つのうち、一番小さいものが現在の上限です。上限を超えていたときに、その値へ即座に切り下げてはいけません。曲率はコーナーの頂点で跳ね上がりますし、譲る判断も立つ瞬間があります。そこで切り下げると、1フレームで速度が上限まで落ちて、物理的にありえない急減速になります（実際「急に大きく減速する」という形で現れました）。

今は**その車の最大減速度を超えない範囲で**上限へ近づけます。上限を下回っているときは、加速側の計算にそのまま任せます。

**曲げているのは速度ではなく、向き**

ここまでは速度の話で、実際に車を曲げているのは進行方向のほうです。車は毎フレーム、自分が乗っているレーンの最寄り点から進行方向を読み、その向きへ速度×時間だけ進みます。

この方式には弱点があります。向きは**その地点での接線**なので、曲線の上を進んでいるつもりでも、実際には接線に沿った直線を1フレームぶん進むことになり、カーブでは毎フレームわずかに外側へ膨らみます。1フレームで進む距離に比例するので、速い車ほど大きくなります。

さらに問題なのは、**一度ついた横のズレを戻す仕組みが無かった**ことです。位置は向きを積み上げた結果でしかないので、交差点で少し外へ膨らめば、そのズレを持ったまま出口の直線を走り続けます。

（図：接線方向に進むことで外へ膨らむ）

**横方向にだけ、レーンへ引き戻す**

そこで位置を更新した直後に、いま乗っているレーンの最寄り点へ向けて車を寄せる処理を足しました。ポイントが3つあります。

ひとつ目は、**前後方向には動かさない**こと。寄せるベクトルから進行方向の成分を取り除き、横方向だけを使います。前後に動かすと、前の車との車間距離や交錯点までの距離が変わり、追従や譲り合いの判断そのものを揺らしてしまいます。位置を直したいだけなのに判断が変わるのでは、直したことになりません。

ふたつ目は、**寄せる強さを「進んだ距離あたり」で決める**こと。1秒あたりで決めると、ゆっくり走っている車ほど同じ距離を進む間に強く引き寄せられ、速度によって軌跡が変わります。それはまさに今回直したかった症状なので、時間ではなく距離を基準にします。こうすると、何km/hで曲がっても同じ線をたどります。

みっつ目は、**ズレが大きすぎるときは寄せない**こと。交差点の中は、右折・左折・直進のコネクタが同じ出口レーンへ集まっていて、最寄りのレーンを取り違える余地があります。数メートル単位でずれているのは「補正が必要な状態」ではなく「別のレーンを参照してしまっている状態」の疑いが濃いので、そのときは値をデバッグ用の属性に残すだけにして、位置は触りません。**間違った状態を、黙って正しい見た目にしてしまわない**ためです。

## 調整表

| 症状 | 触るもの |
|---|---|
| カーブの進入が速すぎる | カーブ速度の比率を下げる |
| カーブ手前でガクッと落ちる | 最大減速度、または`curv`の焼き方（頂点だけ跳ねていないか） |
| 右折が遅すぎる | 右折徐行の比率を上げる。または「譲っているときだけ」の条件が効いているか確認 |
| カーブで外へ膨らむ／出口でレーンからずれる | 横方向補正の強さを上げる |
| コーナーで横に飛ぶ | 横方向補正の強さを下げる |
| 横ズレのデバッグ値が交差点で跳ねる | 補正の問題ではなく、参照しているレーンが間違っている |

## この節で言いたかったこと

速度の上限を作るのは簡単で、難しいのは**落とし方**と**戻し方**です。上限を切り下げるだけでは物理的にありえない動きになり、向きだけを積み上げるとズレが永久に残ります。どちらも「正しい値を計算する」問題ではなく、「正しい値へどう近づけるか」の問題でした。
